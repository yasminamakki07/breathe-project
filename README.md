Breathe 🌿
AI-Powered Breathing Support and Progress Tracking System
About the Project : 

Breathe is a wellness-focused web application designed to encourage breathing exercises, personal reflection, and healthy relaxation habits.

The project explores how artificial intelligence can support users through safe, personalized, and encouraging interactions while maintaining clear boundaries as a supportive wellness tool rather than a medical or therapeutic application.

Users can complete guided breathing sessions, track their progress over time, and receive AI-generated supportive messages based on their personal feedback after each session.

Features
🌬️ Guided breathing exercises with customizable durations and rounds
📊 Personal progress tracking through session history and visual statistics
🤖 AI-generated supportive messages using Google Gemini
👤 User accounts with secure authentication
📱 Responsive interface for different screen sizes
Technologies Used
React.js
Node.js & Express.js
MySQL
Google Gemini API
